Other files in `work/`: `semantic_cache/` (LLM query rewrites), `semantic_debug.json`,
`scene_plan.prev.json` (backup), `run_log.jsonl` (stage timings, read by the dashboard),
`dashboard_frames/`. The CLI is `src/cli.py` (typer); the dashboard is `src/dashboard.py`.

Invalidation: stages 1-3 compare file mtimes with their inputs; stages 4-5, which write paths
back into the plan, compare content signatures. A hand-edited plan is detected by signature and
protected unless `--force`.

## Scene plan schema

`work/scene_plan.json` = `{episode_id, beats: [...]}`; beats are contiguous and cover the voice-over.

| Field | Meaning |
|---|---|
| `start_time`, `end_time` | Seconds |
| `visual_template` | `fullscreen_clip`, `split_schematic`, `cutout_callout`, `punch_in_emphasis` |
| `beat_style` | `normal`, `deadpan`, `hype`, `technical`, `fail` |
| `primary_source` | `local`, or `stock` with `search_queries` |
| `source_id` | Fullscreen/punch: media. Split: left media. Cutout: blurred background |
| `overlay_asset` | Split: diagram (right). Cutout: subject to cut out |
| `callout_text` | 2-5 words: badge (cutout/split) or lower-third |
| `emphasis` | Micro-punch at beat start |
| `transition`, `transition_duration` | Join INTO this beat: `none`, `crossfade`, `dissolve`, `fadeblack`, `fadewhite`, `zoomin` (`smoothleft`/`slideleft`/`wipeleft` are accepted but rendered as `crossfade`) (+ glitch variants from the theme); overlap must stay below 40 % of the shorter neighbour |
| `media_start`, `media_end`, `overlay_start` | Trims (seconds) |
| `clip_audio`, `clip_audio_gain` | `off|on|duck` |
| `overlay_mode: pip`, `pip_asset`, `pip_corner`, `pip_start`, `pip_delay` | Picture-in-picture |
| `highlights`, `crop_region` | Diagram highlights; photo detail crop `[x,y,w,h]` |
| `visual_query`, `match_score`, `beat_reason` | Planner provenance |
| `media_path`, `stock_asset_id`, `license_type`, `cutout_path`, `badge_path`, `lower_third_path` | Generated by stages 4/5 |

## Templates

`fullscreen_clip` (drift/pan on stills, static clips), `punch_in_emphasis` (perspective-warp zoom,
ease-out), `split_schematic` (640 px footage + 1136 px diagram, legibility rule),
`cutout_callout` (rembg subject over blurred background; falls back to a framed card when the
quality gate rejects the cut-out). Camera moves use a floating-point `perspective` warp, not `zoompan`.

## How matching works

1. Clips are split into shots (PySceneDetect, 3 s windows if missing); 1-3 keyframes per shot are
   embedded (SigLIP2, or Ollama captions + `nomic-embed-text`), cached by file hash.
2. The LLM rewrites each narration beat into concrete visual queries (cached per episode).
3. Per beat the top-k local assets (+ the stock pool) are retrieved with a trim interval.
   Sidecar/filename terms add a prior; diagrams are ranked by sidecar text plus description
   embeddings (SigLIP cannot read diagrams).
4. Global assignment (Hungarian over capacity slots) distributes assets across the whole episode:
   reuse caps, reuse window, unused-asset bonus, clip bonus for actions, minimum clip share,
   near-duplicate families, state penalties. Reuses get a different crop, segment or highlight.
5. The LLM picks among the retrieved candidates; invalid answers are re-asked once, then repaired
   deterministically. `variety.py` then converts plain fullscreen beats toward the target mix.
6. Stage 4 verifies stock candidates visually against the query before accepting them.
